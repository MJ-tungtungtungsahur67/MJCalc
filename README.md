# MJCalc

A simple calculator made with Python and Tkinter.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Errors

  * P.S. Might include some roasts
  * Division-by-zero errors
  * etc.
* Ans button
* Dark UI
* Clear button
* Display-only calculator entry

## Requirements

You can use the `MJCalc.py` file for v1.0.1 or the `.exe` file for v1.0.0.

If you're using the `.py` file, you need:

* Python 3
* Tkinter

If you're using the `.exe` file, you don't need anything. Just download the file and run it!

## Running MJCalc

For the `.py` version, run:

```bash
python MJCalc.py
```

For the `.exe` version, just double-click it and hop right in.
